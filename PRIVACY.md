# Privacy Policy

PoE2 Marketwright is an unofficial Microsoft Edge extension for the official Path of Exile 2 Trade site. This policy describes how the extension handles information.

This project is not affiliated with Grinding Gear Games or Microsoft.

## Data we do not collect

The extension does not have accounts, analytics, advertising, or a developer-operated backend. We do not collect names, emails, payment data, authentication secrets, or browsing history, and we do not sell or share user data.

## Data stored on your device

Settings, item favorites, search-link favorites, and local history are saved with the browser's `storage` API on your device so they persist between visits. You can remove this data by clearing the extension's site data or uninstalling the extension.

## Clipboard

When you click a Path of Building copy control, the extension writes item text to the clipboard. That happens only after an explicit click.

## Network requests

The extension contacts only:

- `pathofexile.com` and `*.pathofexile.com`, to run on `/trade2` and to load official Trade item, stat, and listing data
- `api.poe2scout.com`, to load public Exalted, Chaos, and Divine reference rates for the league shown in the current Trade URL

Requests to the official Trade site may use your existing Path of Exile browser session so the official API can return English catalog or listing data. Poe2Scout requests do not send cookies. These requests go to those services under their own policies, not to the extension author.

## Contact

Questions or privacy requests: https://github.com/WAY29/poe2-marketwright/issues

# 隐私政策

PoE2 Marketwright 是用于《流放之路 2》官方市集的非官方 Microsoft Edge 扩展。本政策说明扩展如何处理信息。

本项目与 Grinding Gear Games、Microsoft 均无隶属关系。

## 我们不收集的数据

扩展没有账号、分析、广告，也没有开发者运营的后端。我们不收集姓名、邮箱、支付信息、登录凭据或浏览历史，也不出售或共享用户数据。

## 保存在你设备上的数据

设置、物品收藏、搜索链接收藏和本地历史通过浏览器的 `storage` API 保存在你的设备上，以便下次访问时仍可使用。清除扩展数据或卸载扩展即可删除这些内容。

## 剪贴板

只有在你点击 Path of Building 复制按钮后，扩展才会把物品文本写入剪贴板。

## 网络请求

扩展只会访问：

- `pathofexile.com` 及 `*.pathofexile.com`：在 `/trade2` 上运行，并加载官方物品、词缀和列表数据
- `api.poe2scout.com`：按当前市集 URL 中的联盟加载公开的崇高、混沌、神圣汇率

向官方市集发出的请求可能使用你已有的 Path of Exile 浏览器登录状态，以便官方接口返回英文目录或列表数据。Poe2Scout 请求不发送 cookie。这些请求发往上述服务，适用对方的政策，而不是发给扩展作者。

## 联系

问题或隐私请求：https://github.com/WAY29/poe2-marketwright/issues
